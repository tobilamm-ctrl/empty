    Spielregeln
    • Ein geheimer Code besteht aus 4 Steckern in 6 Farben (Klassisch) oder 5 Steckern in 8 Farben (Knifflig). Eine Farbe darf mehrmals vorkommen.
    • Du hast höchstens 10 Versuche. Jeder Versuch ist eine vollständige Reihe Stecker.
    • Nach jedem Versuch gibt es Hinweise: ein schwarzer Stift heißt „richtige Farbe an der richtigen Stelle“, ein weißer Stift heißt „richtige Farbe, aber an einer anderen Stelle“. Welcher Stecker gemeint ist, verraten die Stifte nicht.
    • Jeder Stecker im Code zählt nur einmal. Beispiel: Code Rot Rot Blau Gelb, Versuch Rot Blau Blau Blau ergibt 2 schwarze Stifte (Rot vorne, Blau an Stelle 3) und keinen weißen.
    • Jede Farbe trägt zusätzlich ein Zeichen (Punkt, Dreieck, Quadrat, Kreuz, Raute, Stern, Ring, Balken), damit man sie auch bei Farbschwäche unterscheidet.
    • Allein: Der Computer denkt sich einen Code aus. Je weniger Versuche du brauchst, desto besser. Dein Bestwert bleibt auf diesem Gerät gespeichert.
    • Zu zweit: In jedem Durchgang legt einer verdeckt einen Code, der andere rät. Danach wird getauscht. Wer den Code legt, bekommt so viele Punkte, wie der andere Versuche braucht. Wird der Code nicht geknackt, gibt es 11 Punkte. Nach allen Durchgängen gewinnt, wer mehr Punkte hat.
    • Bedienung: Farbe antippen, sie landet im nächsten freien Loch. Ein gesteckter Stecker wird durch Antippen wieder herausgezogen. Am Rechner gehen auch die Zifferntasten, Rücktaste und Eingabe.
