# Arbeitsplatz Medizinische Fachangestellte – Hör-Mindmap

Startseite: `index.html` (Mindmap mit 5 Audios). Jede Überschrift hat eine Unterseite zum Mitlesen (`index.html#t1` … `#t5`).

**Foto einsetzen:** Ein Bild mit dem Namen `mfa.jpg` in diesen Ordner legen. Es erscheint dann automatisch rund in der Mitte. Ohne Foto wird eine Zeichnung gezeigt. Bitte nur Fotos mit passender Lizenz verwenden (z. B. eigenes Foto, Pixabay, Wikimedia Commons).

**Auf GitHub veröffentlichen:** Repository → Settings → Pages → Branch wählen, Ordner `/ (root)`. Die Seite ist dann unter `…github.io/<repo>/webseite-mfa/` erreichbar.
